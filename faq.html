Frequently Asked Questions

Everything you need to know about Kinetica.css.

Is Kinetica free to use?

Yes! Kinetica is completely open-source and free to use in both personal and commercial projects.

Can I use this with React, Vue, or Angular?

Absolutely. Since Kinetica is a pure CSS library, it is framework-agnostic. You can simply add the class names dynamically in your React components (using className) or Vue templates just as you would with normal CSS.

How do I trigger an animation on scroll?

Kinetica does not include JavaScript for scroll detection. However, you can easily pair it with a library like IntersectionObserver or AOS (Animate On Scroll). Simply configure your observer to add the animated and animation name classes when the element comes into view.

Is it bad for performance to use many animations?

All animations in Kinetica are built using `transform` and `opacity` properties, which are GPU-accelerated by modern browsers. This means they are highly performant. However, animating too many elements at once on a single page can still cause lag, especially on low-end mobile devices, so use them tastefully.

How can I create my own custom timing?

You can override the CSS variables provided by Kinetica in your own stylesheet. For example, you can set --kinetica-duration: 4s; on a specific element to make its animation last 4 seconds.
